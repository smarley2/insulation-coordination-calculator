# IEC 62477-1:2022 Slice E1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract Tables 26 through 30 of IEC 62477-1:2022 as the typed impulse procedure, impulse-selection decision table, both dielectric-value tables, and partial-discharge procedure.

**Architecture:** Declarative specs in a new `recipes/iec62477_1_2022/verification.py`, projected through the recipe-declared `grid_projectors` registry Slice D added. Two field tables (26 and 30) project to `ProcedureRule`; three numeric tables (27, 28, 29) project through `project_table`, split into AC and DC routes the way the Table 7 pair already is.

**Tech Stack:** Python 3.12, pydantic v2 frozen models, pdfplumber, pypdf, pytest, ruff, mypy, uv.

**Design spec:** `docs/superpowers/specs/2026-08-10-iec62477-slice-e-design.md`
